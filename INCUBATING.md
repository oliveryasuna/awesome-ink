# Incubating

Ink packages that are worth knowing about but are not in the readme yet.

Everything here has to be installable, has to work with a current Ink, and has to be actively maintained. What it does not have to be is popular. The readme has a star and download floor that a good package can take a couple of years to reach, or never reach at all if it solves a narrow enough problem, and dropping those on the floor in the meantime seemed like the wrong call.

This is a queue, not a rejection pile. I go through it every few months and move things up. If something here has grown past the floor and I have not noticed, open an issue and say so.

Read [CONTRIBUTING.md](CONTRIBUTING.md) before adding anything. Same formatting rules, same four requirements, no popularity floor. Adding your own work is fine.

Nothing here is endorsed the way the readme entries are. Some of it will turn out well, some of it will get abandoned, and I have not audited any of it beyond checking that it installs and runs.

## Graduating

A package moves to the readme when it clears the floor in [CONTRIBUTING.md](CONTRIBUTING.md) and still passes the four requirements. Author interest counts for something too. A package whose author has stopped answering issues is not going to get promoted just because the star count crossed a line.

Things also leave this file in the other direction. If a package here goes stale, breaks against a current Ink, or gets archived, it comes out. No hard feelings, and it can come back if it gets picked up again.
